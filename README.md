# Constrained Gaussian Random Fields

This repository contains the tensile testing data used in the paper **[Constrained Gaussian Random Fields with Continuous Linear Boundary Restrictions for Physics-informed Modeling of States](https://arxiv.org/abs/2511.22868)**. 

The dataset consists of discrete displacement measurements collected during a tensile testing experiment and analyzed in Section 4.4 of the paper. These measurements are used to evaluate the proposed constrained Gaussian random field (cGRF) framework for estimating a spatio-temporal displacement field while incorporating known physical boundary conditions. In particular, the case study demonstrates how incorporating boundary information can improve predictive performance and uncertainty quantification.
