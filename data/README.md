## Tensile testing data

This folder contains the tensile testing data analyzed in Section 4.4 of the paper **[Constrained Gaussian Random Fields with Continuous Linear Boundary Restrictions for Physics-informed Modeling of States](https://arxiv.org/abs/2511.22868)**.

The data is provided by Artur Leonel Machado Ulsenheimer and Calvin M. Stewart, and it consists of discrete displacement measurements during a tensile testing experiment. The experiment is conducted on a polycarbonate dog-bone-shaped specimen prepared according to ASTM D638, an industry standard for determining material properties under pulling forces. Each CSV file corresponds to a single time step of the experiment.
