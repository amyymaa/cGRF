Folder kernel contains closed-form mean and covariance functions of cGRFs and relevant visualizations.

Folder Tensile-smoothing contains implementations of boundary-constrained estimation of displacement field using COMSOL simulated data.

Folder Tensile-smoothing-real contains analysis of real tensile testing data.

Folder PDE-solver contains implementations of PDE solvers of heat equation.
    The code is adpted from https://github.com/ochkrebtii/uqdes.

Folder PDE-discovery contains implementations of data-driven discovery of Burger's equation.
    The code is adpted from https://github.com/ACDS-code/ACDS.
