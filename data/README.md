## Tensile testing data

This folder contains the tensile testing data analyzed in Section 4.4 of the paper **[Constrained Gaussian Random Fields with Continuous Linear Boundary Restrictions for Physics-informed Modeling of States](https://arxiv.org/abs/2511.22868)**. 

The data consists of discrete displacement measurements during a tensile testing experiment conducted by Artur Leonel Machado Ulsenheimer and Calvin M. Stewart. These measurements are used to evaluate the proposed constrained Gaussian random field (cGRF) framework for estimating the spatio-temporal displacement field while incorporating known physical boundary conditions.
